Phase Breakdown
Phase 1: Foundation (months 1-3)
CBOR encoder/decoder for all eras, multiplexer, handshake, basic ChainSync consumer. At the end of this phase: can connect to a Haskell node and receive headers.
Phase 2: Sync (months 3-6)
BlockFetch, ledger rules (all 7 eras), ChainDB storage, hard fork combinator. At the end: can sync from genesis to tip.
Phase 3: Production (months 6-9)
VRF/KES crypto, block forge pipeline, TxSubmission, mempool, operational certificates. At the end: can produce valid blocks.
Phase 4: Hardening (months 9-12+)
Crash recovery, memory optimization, epoch boundary processing, 10-day stability testing, edge case fixes. At the end: challenge-ready.
Honest Assessment: No alternative Cardano node implementation has achieved full spec compliance yet. Amaru (TxPipe, Rust) has been in development for 2+ years with a funded team. Dolos (TxPipe, Rust) focuses on a data node subset. The challenge requires FULL compliance including block production. A solo developer with AI assistance is looking at 12-18 months minimum for a credible attempt.
